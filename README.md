# بوابة العقارات (Aqar Gateway) — تطبيق Flutter

منصة لعرض العقارات بجميع أنواعها للبيع والإيجار، تتيح لأي مستخدم مسجّل
نشر إعلان عقاره (صور + بيانات + وسائل تواصل)، ولمالك المشروع إدارة فريق
من الإداريين بصلاحيات مخصصة لكل واحد منهم.

## المزايا المضمّنة

- **شاشة ترحيبية (Splash)** متحركة بهوية بصرية للتطبيق.
- **شاشة رئيسية** تعرض العقارات مع:
  - بحث فوري بالعنوان أو الموقع.
  - تبويب سريع بين "الكل / للبيع / للإيجار".
  - فلاتر حسب نوع العقار (شقة، فيلا، أرض، مكتب، محل، شاليه).
  - قسم "عقارات مميزة" بعرض أفقي.
  - شبكة عقارات (Grid) بطاقات ببطاقات صور متقلبة.
- **تسجيل الدخول / إنشاء حساب** بالبريد وكلمة المرور فقط — بدون أي
  تأكيد عبر البريد الإلكتروني، التفعيل فوري.
- **بطاقة عرض العقار (PropertyCard)**: صور متعددة قابلة للتمرير
  (Carousel) مع مؤشر نقاط، شارة (للبيع/للإيجار)، شارة "مميز"، وزر مفضلة.
- **شاشة تفاصيل العقار**: عرض صور بالحجم الكامل، السعر، المساحة، عدد
  الغرف والحمامات، الوصف، بيانات المعلن، وأزرار اتصال مباشر وواتساب.
- **إضافة عقار جديد**: رفع صور من المعرض، اختيار الغرض والنوع، إدخال
  كل بيانات العقار وبيانات التواصل، وربطه تلقائياً بحساب المستخدم.
- **لوحة تحكم مالك المشروع**: إحصائيات سريعة (عدد العقارات/المستخدمين/
  الإداريين)، إضافة إداري بالبريد الإلكتروني، ومنح/سحب صلاحيات دقيقة
  لكل إداري (إدارة العقارات، إدارة المستخدمين، إدارة الإعلانات
  المميزة، عرض التقارير).
- **المفضلة**: حفظ العقارات التي يهتم بها المستخدم للرجوع إليها لاحقاً.
- **الملف الشخصي**: عرض بيانات المستخدم، دوره (مالك/إداري/مستخدم)،
  عقاراته الخاصة، ورابط لوحة التحكم إن كان مالكاً.
- تصميم **Material 3** كامل مع دعم **RTL** للغة العربية، وخط Cairo.

## ملاحظة مهمة

هذا التطبيق يعمل حالياً بالكامل على **بيانات محلية في الذاكرة**
(Mock/In-memory State) دون أي خادم فعلي، وذلك ليكون جاهزاً للتجربة
والتعديل فوراً. عند إعادة تشغيل التطبيق تُعاد كل البيانات (حسابات جديدة،
عقارات مُضافة) إلى حالتها الافتراضية.

للانتقال إلى الإنتاج الفعلي، يُنصح بربط المشروع بخدمة خلفية مثل
**Firebase** (Authentication + Firestore + Storage) أو أي API خاص بك،
عبر استبدال منطق `AuthProvider` و`PropertyProvider` بنداءات شبكية
حقيقية مع الحفاظ على نفس الواجهات (نفس أسماء الدوال) — بحيث لا تحتاج
لتعديل أي شاشة.

## البناء التلقائي عبر GitHub Actions (مجاني بالكامل)

المشروع يحتوي الآن على ملف `.github/workflows/build.yml` جاهز، وهذه خطوات تفعيله:

1. أنشئ مستودع (Repository) جديد على GitHub وارفع محتويات هذا المجلد إليه:
   ```bash
   git init
   git add .
   git commit -m "أول إصدار من بوابة العقارات"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
2. بمجرد الرفع، سيبدأ GitHub تلقائياً ببناء ملف APK (تقدر أيضاً تشغّله يدوياً من
   تبويب **Actions** داخل المستودع عبر زر **Run workflow**).
3. بعد اكتمال البناء (يأخذ عادة 5-10 دقائق)، افتح تبويب **Actions** ← اختر آخر
   عملية بناء ← ستجد ملف **aqar-gateway-release-apk** في قسم **Artifacts**،
   حمّله وثبّته مباشرة على جهاز أندرويد.

ملاحظات:
- إذا كان المستودع **عاماً (Public)** فالبناء مجاني تماماً بلا أي حد شهري.
- إذا كان **خاصاً (Private)** فلديك حصة مجانية شهرية من GitHub (تكفي لعشرات
  عمليات البناء لمشروع فردي)، وتُجدَّد كل شهر.
- يمكنك تغيير رقم إصدار Flutter المستخدم في السطر `flutter-version` داخل
  الملف إذا احتجت نسخة أحدث لاحقاً.

## أفكار لتوسيع التطبيق لاحقاً

- ربط بخريطة (Google Maps) لعرض موقع العقار على الخريطة.
- إشعارات Push عند إضافة عقار جديد يطابق اهتمامات المستخدم.
- نظام تقييمات ومراجعات للمعلنين.
- خاصية "مقارنة العقارات" جنباً إلى جنب.
- الدفع لتمييز إعلان عقار (Featured Listing) عبر بوابة دفع.
- لوحة تقارير وإحصائيات مفصّلة (أكثر العقارات مشاهدة، أكثر المدن بحثاً).
